### Exact Data Shape of a Reputation Reason
Each reason in `observer.reputationReasons[targetName]` has the following schema:
```js
{
  kind: 'theft-witnessed', // string: 'theft-witnessed' | 'theft-rumor' | 'child-harm' | 'child-neglect' | 'fire-refusal' | 'fire-aid' | 'trade-fair' | 'interaction'
  by: 'Bram',              // string: name of villager the reputation reason is about
  day: 41,                 // number: sim day recorded (Math.floor(W.day))
  weight: -1.0,            // number: base weight (-1.0 for severe violations, +0.25 for prosocial acts)
  decay: 0.95,             // number: per-day exponential decay rate (multiply by decay^days)
  confidence: 1.0,         // number: 1.0 for direct witness, ~0.68 for 1-hop gossip
  source: 'direct',        // string: 'direct' | 'gossip' | 'hearsay'
  teller: null,            // string|null: speaker name if received via gossip
  victim: 'Marta',         // string|null: affected victim if applicable
  distorted: false         // boolean: true if modified by gossip distortion
}
```
Effective weight at current time `nowDay` is:
`effWeight = weight * Math.pow(decay, nowDay - day) * confidence`.
When `Math.abs(effWeight) < 0.02` (epsilon), the reason is dropped (pruned).
Trust function:
`calculateTrust(observer, target)`:
- If target is actively ostracized in village or by observer: returns `0.0`.
- If no reasons exist: returns baseline `clamp(baseTrust, 0.05, 0.95)`.
- If severe violation reason exists (effective weight <= -0.4): trust collapses to `<= 0.05`.
- Otherwise: `clamp(baseTrust + sum(effWeights), 0.0, 1.0)`.
- `explainTrust(observer, target)` provides transparent breakdown of all reasons and effective weights.

### How Gossip Distorts (Code Path)
Located in `src/systems/12d_social.js:spreadGossip(speaker, listener, forcedRumor)`:
1. **Selection**: Speaker selects highest-salience social reason or memory about any third party (`speaker.reputationReasons[targetName]`), or uses `forcedRumor`.
2. **1-Hop Distortion Transformations**:
   - **Confidence reduction**: `distortedConf = Math.max(0.2, originalConf * 0.75)` (e.g. 1.0 -> 0.75, 0.9 -> 0.68).
   - **Weight attenuation**: `distortedWeight = +(rumor.weight * 0.85)`.
   - **Kind shifting**: Eyewitness events morph into rumor claims:
     - `'theft-witnessed'` -> `'theft-rumor'`
     - `'child-harm'` -> `'child-harm-rumor'`
     - `'fire-refusal'` -> `'fire-refusal-rumor'`
   - **Source & Teller provenance**: marked with `source: 'gossip'`, `teller: speaker.name`, `distorted: true`.
   - **Detail shift on 'who'**: if `rumor.mistakenWho` is present (mistaken witness / false rumor), accusation targets the innocent villager.
3. **Listener Belief & Reputation Formation**:
   - `addReputationReason(listener, targetPerson, gossipReason)`: records the reason in listener's opinion of target.
   - If severe violation (`distortedWeight <= -0.4`): listener ostracizes target (`setOstracism(targetPerson, 5, listener)`), collapsing listener's trust to ~0.
   - `observe(listener, ...)`: records hearsay belief with topic `'gossip_' + targetPerson` and source `'hearsay'`.
   - A false rumor creates a real negative reputation entry on an innocent character without any crime having occurred.

### Role Vacancy Pipeline
Located in `src/systems/12d_social.js:fillRoleVacancy(role, options)`:
1. Gathers eligible living adult candidates.
2. Electors = all living adults (`e !== c`).
3. `collectiveTrust(c) = (1 / |E|) * sum(calculateTrust(e, c))`.
4. Disqualification: if candidate is ostracized or `collectiveTrust < 0.2`, `score = -1.0` (disqualified).
5. Suitability bonus (hunting/brave for guard, medicine for healer, age for village head) breaks ties between honest candidates, but cannot save a disqualified candidate.
6. Highest scoring candidate is elected, role assigned (e.g. `'Village Guard'`, `'Village Healer'`, `'Village Head'`), logged and returned. A thief caught red-handed is ALWAYS skipped even if having maximum combat stats.
