# realWorld — Natura, the living valley

A causal "watchmaker universe": a cozy living-valley simulation where AI-driven
inhabitants perceive, remember, plan, work, bond, reproduce, age, and die —
and the world keeps running with or without an observer.

- `natura-v4.html` — the current living build (open in a browser)
- `natura-v1/v2/v3.html` — earlier generations
- `farm_v1.js` — farming module (crops, chickens, eggs; deterministic animal instincts, zero AI tokens)
- `patch_v4.py` — build script that assembles `natura-v4.html`
- `nv.py` — helper to inspect / order the valley's souls
- `*_brief*.md`, `*_diary.md` — founder briefs and diaries
- `sprites/` — generated pixel-art sprites
- `design_log.md` — design-spirit log
