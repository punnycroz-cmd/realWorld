## Rules for use

- Spotlight teasers are spoiler-safe per SOCIAL-LAUNCH-PLAN §4 — the copy
  on each card teases, never confirms. Do not edit text onto cards by
  hand; change the source in `make_social_cards.py` and regenerate.
- `card-receipt.png` carries a baked DEMO badge: pre-launch it is the
  honest stand-in for `{{RECEIPT_SHOT}}`. Post-launch, prefer a real
  feed/receipt capture; this card is the fallback, not the default.
- HUD/UI panels visible in some captures (inspector, REC cluster) are
  part of the real build — caption posts "development build" per §8.
- Alt text for every card lives in `social/alt-text.md` §cards.
- Rebuild after any shot rebase: `python3 tools/make_social_cards.py`.
