# Devlog clip scripts — TikTok / YouTube Shorts / X video

15–45s each. Captioned for sound-off. Until a capture rig produces video,
these run as ken-burns pans over `site/shots/v16-*.png` (marked
"development build"). When the game ships, re-cut from live capture —
scripts unchanged.

Clip format skeleton: cold-open text card (2s) → footage (10–35s) →
end card "Watch free — {{URL}}".

---

### Clip 1 — "It's always Tuesday for somebody" (T-14 teaser)

- Card: "Somewhere in the Mission District, right now —"
- Footage: v44-D evening shot, slow push-in. If live capture exists by
  launch: a resident crossing the park path at dusk.
- VO/on-screen text: "twenty-eight people are awake. Working, arguing,
  planning. All fictional. All live."
- End card.
