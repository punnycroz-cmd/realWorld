# "This Week on the Block" — recurring recap template

Cadence: every Sunday, all primary channels (X thread or single post +
image; Bluesky condensed; itch devlog long-form monthly roll-up).
Source material: the public request feed + observed character activity.
Honesty rule: only real events. A quiet week is a quiet week — say so.

---

## Template

**Title line (X/Bluesky):**

> This Week on the Block — {{DATE RANGE}}:

**Body beats (pick what actually happened, in this order):**

1. **The headline** — the week's biggest in-world event, one line:
   > "Two rainstorms hit the block — both were requested."
2. **The feed** — notable player requests, attributed (the feed already is):
   > "Viewer @{{handle}} put on a rooftop set Friday night. 40 people
   > watched live."
3. **The residents** — what the mains did, soap-opera register:
   > "Tomás finally showed someone the notebook."
4. **The numbers** — optional honesty beat:
   > "{{N}} requests filed, {{N}} approved, {{N}} refunded."
5. **Next week hook:**
   > "The flyer about the Guerrero buildings is still circulating."

**Footer:** "Watch free: {{WATCH}}"

> This Week on the Block — Sept 22–28:

## Production notes

- Keep it under ~10 lines for social; the itch devlog version can run long.
- Pull numbers from the request feed, never estimates.
- If a week produced a genuinely great emergent moment, break format and
  just tell that story. The template serves the block, not the reverse.
