Every case where money moves back.

This is the complete refund policy — the same matrix the game implements, written in sentences. The rule underneath all of it: you pay for a request that ran, not for one that didn't. Refunds and compensation post to the public feed like everything else.

The matrix

What happens to your credits.

Denied at screening — never charged

If a request is denied, the hold is released and nothing moves. Every denial refunds in full, every time — there is no "screening fee" and never will be. Denied request text never appears on the public feed.

Expired in queue — auto-refund

Queued requests wait first-come. If a request expires before it can run, the credits return automatically — no ticket, no asking. The hold clock shows the time left while it waits.

Approved with a trim — it's an offer

If a reviewer approves a request with reduced scope, it comes back to you as an offer at the new price: accept the trim or decline for a full refund. Nothing runs until you say so.

Revoked mid-run — compensated

If an admin stops a running request, affected players are compensated and the action posts to the feed publicly — admin interventions carry receipts too.

Appeal reverses a denial — original quote

One appeal per denial, within 72 hours, to a different reviewer. A reversal puts the request back in review at its original price; you're charged only if it's approved.

Ran and resolved — final

A request that ran to completion is spent — even if residents didn't react the way you hoped. You bought the ask, not the outcome; emergent refusal is the game working, not a defect. Session-based possession that ends early ("player session ended") follows the same rule for time used.

The currency

About credit purchases.

Unspent credits

Credits are a non-transferable, non-redeemable game currency with no cash value — they are not a stored-value product and don't cash out. Where your jurisdiction gives a withdrawal right on digital goods, the policy honors it; otherwise unspent-credit refunds are reviewed case by case at the contact below.

Chargebacks

Please use the appeal path or the contact address before disputing a charge — a chargeback reverses the purchase and claws back the credits it bought, and repeated chargebacks can close the account. The ledger keeps the receipts either way.
