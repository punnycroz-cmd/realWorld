# Jobs — workplace cards (world v3)

The job board in `world/jobs-housing.md` §2 is the canonical wage/headcount
table. This directory is the **depth layer**: what each workplace is like
from inside, so any AI (or player-hired character) can work a shift there
consistently.

Card discipline, same as the ambient cards:

- Everything here is **surface knowledge** — what a coworker would pick up
  in a month. No character SECRETS appear; workplace texture is not a
  leak channel.
- **Conditions, not scripts.** Cards describe staffing, tempo, failure
  modes, culture, and pay mechanics. They never say "when X happens,
  character does Y" — the AI decides behavior in character.
- Wages/hours duplicate `jobs-housing.md` §2 for convenience; if they
  ever disagree, **jobs-housing.md wins** and this file is stale — fix it.
- All business names are canonical parody names (`world/businesses.md`).

## Hiring rules of the world (apply everywhere)

- Openings marked **open** on the board are what player-hired characters
  apply for in the v6 creation flow. Cast-held jobs are fiction, not
  vacancies.
- Hiring is a condition check, not a cutscene: each card lists what the
  employer screens for (reliability, papers, knife skills, availability).
  Nobody hands out jobs for charm.
- Pay is baseline game-$/h; thin-AI auto-shifts pay baseline; possessed
  play can earn the shift bonus noted per card (+10–20% cap, plan §2.4).
- Payday cadence: weekly for entry/informal, biweekly for mid/top
  (jobs-housing §5).
- A workplace card never contains a script hook for drama. If a seed
  touches a workplace (Tomás's notebook, Marisol's blog), the card says
  the workplace is *unaware* — the seed stays in the bible.
